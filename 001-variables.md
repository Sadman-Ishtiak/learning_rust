# Variables
1. We assign rust variables using `let` keyword 
2. To use the standard command line print we use `print!()` or `println!()` to print the values of the variables.
3. Scope of a variable is defined by the block of code in which it is declared. 
4. A function is a named block of code that is reusable
5. Shadowing allows a variable to be re-declared in the same scope with the same name
