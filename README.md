## Getting Started
To run the code in this repository, ensure you have Rust installed.

1. Install Rust via rustup:
   ```bash
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```
2. Clone this repository:
   ```bash
   git clone https://github.com/Sadman-Ishtiak/learning_rust.git
   cd learning_rust
   ```
3. Run a sample (e.g., `000-hello.rs`):
   ```bash
   rustc 000-hello.rs
   ./000-hello
   ```
