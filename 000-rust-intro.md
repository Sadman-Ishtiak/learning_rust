# Learning Rust
This is the repository of mine that is storing the step by step note of me learning the Rust Programming Lanugage

## Why learn rust?
1. Rust has a very fast execution time
2. It has a strict type system
3. It does not have a garbage collection
4. It is memory safe
5. It provides useful compiler output
6. High chance of adoption of this language in various parts or works

## Book
1. The Rust Programming Languages
2. Rustlings
3. Rust By Example 
4. Rust by practice
5. Rust for Rustaceans
